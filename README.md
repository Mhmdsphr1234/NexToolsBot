# NexTools — ربات ابزار چندکاره تلگرام (MVP)

## ۰. قبل از شروع: پیش‌نیازهای سیستمی (فقط یک‌بار لازم است)

این پروژه به دو برنامه‌ی سیستمی خارج از پایتون نیاز دارد. لطفاً این‌ها را
**قبل از اجرای ربات** نصب کنید.

### الف) FFmpeg (برای دانلود از یوتیوب/ساندکلاود/اسپاتیفای ضروری است)

1. به آدرس `https://www.gyan.dev/ffmpeg/builds/` بروید.
2. از بخش "release builds"، فایل `ffmpeg-release-essentials.zip` را دانلود کنید.
3. فایل را از حالت zip خارج کنید (مثلاً در مسیر `C:\ffmpeg`).
4. پوشه `C:\ffmpeg\bin` را به PATH ویندوز اضافه کنید:
   - در جست‌وجوی ویندوز بنویسید "Edit the system environment variables" و بازش کنید.
   - روی "Environment Variables" کلیک کنید.
   - در بخش "System variables"، متغیر `Path` را پیدا و ویرایش کنید.
   - "New" را بزنید و مسیر `C:\ffmpeg\bin` را اضافه کنید.
   - روی OK ها کلیک کنید تا ذخیره شود.
5. یک Command Prompt **جدید** باز کنید و تست بگیرید:
```
ffmpeg -version
```
باید اطلاعات نسخه FFmpeg نمایش داده شود.

### ب) Tesseract-OCR با پکیج زبان فارسی (برای قابلیت OCR ضروری است)

1. به آدرس `https://github.com/UB-Mannheim/tesseract/wiki` بروید (نسخه‌ی رسمی ویندوز).
2. آخرین installer (مثلاً `tesseract-ocr-w64-setup-5.x.x.exe`) را دانلود کنید.
3. هنگام نصب، در صفحه انتخاب کامپوننت‌ها (Choose Components)، حتماً وارد
   بخش **"Additional language data"** شوید و تیک **Persian** را بزنید.
4. نصب را با مسیر پیش‌فرض (`C:\Program Files\Tesseract-OCR`) کامل کنید.
5. این مسیر را دقیقاً همان چیزی است که در فایل `.env` (مرحله ۳ پایین) باید
   در `TESSERACT_CMD` قرار دهید.

## ۱. نصب پروژه

فرض می‌کنیم Python 3.11، Git و venv را قبلاً نصب کرده‌اید (طبق Phase 0).

```bash
cd NexTools
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
```

نصب ممکن است چند دقیقه طول بکشد (به‌خصوص کتابخانه‌های yt-dlp و spotdl حجیم‌اند).

---

## ۲. ساخت فایل تنظیمات `.env`

فایل `.env.example` را کپی کرده و اسمش را به `.env` تغییر دهید:

```bash
copy .env.example .env
```

سپس فایل `.env` را باز کرده و مقادیر زیر را با اطلاعات واقعی خودتان جایگزین کنید:

```
BOT_TOKEN=توکنی که از BotFather گرفتید
TESSERACT_CMD=C:\Program Files\Tesseract-OCR\tesseract.exe
```

⚠️ فایل `.env` هرگز نباید در Git کامیت شود (در `.gitignore` هم از قبل مستثنا شده).

---

## ۳. اجرای ربات

```bash
python main.py
```

اگر همه‌چیز درست باشد، در ترمینال چیزی شبیه این می‌بینید:
```
... | INFO | __main__ | NexTools bot is starting...
```

حالا به تلگرام بروید، ربات خودتان را پیدا کنید و `/start` بفرستید.

برای متوقف کردن ربات، در ترمینال `Ctrl+C` را بزنید.

---

## ۴. راهنمای تست هر قابلیت

| قابلیت | نحوه تست |
|---|---|
| شروع کار | `/start` بفرستید؛ باید پیام خوش‌آمد را ببینید |
| دانلود یوتیوب | یک لینک یوتیوب کوتاه (مثلاً یک ویدیوی چند‌ثانیه‌ای) بفرستید |
| دانلود اینستاگرام | لینک یک پست عمومی اینستاگرام بفرستید |
| دانلود پینترست | لینک یک پین بفرستید |
| دانلود ساندکلاود | لینک یک ترک ساندکلاود بفرستید |
| دانلود اسپاتیفای | لینک یک ترک اسپاتیفای بفرستید (کمی کندتر است چون ابتدا در یوتیوب جست‌وجو می‌کند) |
| عکس → PDF | یک عکس بفرستید، روی دکمه "📄 تبدیل به PDF" بزنید |
| عکس → OCR | همان عکس (یا عکس متن‌دار) را بفرستید و روی "🔤 استخراج متن" بزنید |
| چند عکس با هم → یک PDF | چند عکس را هم‌زمان به‌صورت آلبوم انتخاب و ارسال کنید |
| PDF → عکس | یک فایل PDF بفرستید |
| تشخیص آهنگ | یک ویس کوتاه از یک آهنگ معروف ضبط و ارسال کنید، یا فایل صوتی/ویدیویی حاوی موسیقی بفرستید |
| فایل → لینک | یک فایل غیر PDF (مثلاً zip یا docx) بفرستید |
| مدیریت خطا | یک لینک نامعتبر یا از سایت پشتیبانی‌نشده بفرستید؛ ربات نباید کرش کند |

## ۵. محدودیت‌های شناخته‌شده این نسخه MVP (مهم بدانید)

- **اسپاتیفای**: به دلیل DRM، دانلود مستقیم ممکن نیست. آهنگ در یوتیوب جست‌وجو و از آنجا دانلود می‌شود؛ گاهی ممکن است دقیقاً نسخه استودیویی پیدا نشود.
- **حجم فایل**: طبق محدودیت‌های Bot API تلگرام، حداکثر حجم قابل دانلود/ارسال حدود ۲۰-۵۰ مگابایت است (در `.env` قابل تنظیم تا همین سقف).
- **فایل → لینک**: از سرویس رایگان و عمومی 0x0.st استفاده می‌شود؛ لینک‌ها عمومی و موقت هستند (نه یک فضای ذخیره‌سازی اختصاصی).
- **OCR روی چند عکس**: اگر چند عکس با هم (آلبوم) بفرستید، دکمه OCR فقط روی اولین عکس اجرا می‌شود.
- **بدون پایگاه داده**: فعلاً هیچ اطلاعاتی از کاربران ذخیره نمی‌شود (طبق نقشه راه، این در فاز بعدی اضافه می‌شود).
